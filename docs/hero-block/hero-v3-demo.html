Hero V3 — Variant Sample Draft

Every hero below is built from the same block-table markup an author produces, then decorated by the real blocks/hero-v3/hero-v3.js and styled by blocks/hero-v3/hero-v3.css. Hero V3 is a clean, inline-authored block with no Content Fragment dependency. The base variant is author-controlled; the six named variants lock height, alignment, and image position.
