# XE Footer

The **XE Footer** is the Xcel footer rendered with the `@ignite/web` footer
composition — the same markup as XE Footer V2 and V3 — authored with rich-text
fields:

```html
<xe-footer columns="3">
  <xe-logo slot="logo" variant="inverse" size="md" href="/" label="Xcel Energy Home"></xe-logo>
  <span slot="copyright">© 2026 Xcel Energy Inc. All rights reserved.</span>
  <xe-footer-column heading="Company">
    <xe-hyperlink href="…" variant="variant">Careers</xe-hyperlink>
    …
  </xe-footer-column>
  …
  <xe-icon-button slot="social" size="xl" href="…" aria-label="Facebook (opens in a new window)">
    <xe-icon icon="faSquareFacebook"></xe-icon>
  </xe-icon-button>
  …
  <xe-hyperlink slot="legal" href="…" variant="variant" trailing-icon>Privacy</xe-hyperlink>
  …
  <img slot="banner-image" src="…" alt="">
  <span slot="tagline">Our Energy, Your Power</span>
</xe-footer>
```

The logo isn't authorable: it's Ignite's static Xcel Energy logo, linking to
the homepage. Below 1024px each link column collapses into an accordion
(`<xe-accordion>`). Colors, spacing and typography come from the Ignite design
tokens, loaded by `scripts/components/ignite.js`.

## Authoring model

The controls below map one-to-one to the block's authoring model
(`blocks/xe-footer/_xe-footer.json`). Each field (or element group) renders as
one row, in model order, empty or not:

<table>
  <thead>
    <tr><th>Field</th><th>Model type</th><th>Renders as</th></tr>
  </thead>
  <tbody>
    <tr><td><code>copyright</code></td><td>text</td><td>The copyright line</td></tr>
    <tr><td><code>social</code></td><td>richtext</td><td>Social icon buttons (Facebook, X, Instagram, LinkedIn, YouTube), opening in a new window</td></tr>
    <tr><td><code>legal</code></td><td>richtext</td><td>Legal links with a trailing icon</td></tr>
    <tr><td><code>footerlinks</code></td><td>richtext</td><td>One link column per heading + link-list pair</td></tr>
    <tr><td><code>banner_background</code> + <code>banner_tagline</code></td><td>reference + text</td><td>The full-bleed banner image and its centered tagline</td></tr>
  </tbody>
</table>

Social links can be icon images, EDS icons (`:facebook:`) or text; the network
is recognized from the link's URL, label, icon name or text. A heading without
links yet renders no column. With no social or legal links at all, the live
Xcel Energy footer's links render.

The rich-text links are decorated by the same functions as XE Footer V2's child
items (`blocks/xe-footer-social-links`, `blocks/xe-footer-legal-links`,
`blocks/xe-footer-column-links`); the shared copyright, banner and loading
helpers live in `scripts/components/xe-footer-utils.js`.
