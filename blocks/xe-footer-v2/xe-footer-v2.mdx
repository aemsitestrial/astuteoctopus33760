# XE Footer V2

The **XE Footer V2** is the Xcel footer rendered with the `@ignite/web` footer
composition. The authored content is rebuilt into `<xe-footer>` with slotted
logo, copyright, social and legal links, up to five `<xe-footer-column>` link
columns, and a full-bleed banner with a centered tagline. Links become `<xe-hyperlink>` elements. When no logo is
authored, Ignite's built-in Xcel Energy logo is used.

Below 1024px each link column collapses into an accordion (`<xe-accordion>`).
Colors, spacing and typography come from the Ignite design tokens
(`scripts/ignite/bundle/themes/tokens.css`), loaded by
`scripts/components/ignite.js`.

## Authoring model

The controls below map one-to-one to the block's authoring model
(`blocks/xe-footer-v2/_xe-footer-v2.json`), so this page mirrors what an author edits
in the Universal Editor.

The block is a **key-value block** (`"key-value": true` on its template): every
field renders as a `name | value` row, and the decorator reads each field by
name. A blank field is simply absent, so it can't shift the fields after it.
Link columns are five fixed slots; a slot renders only when it has links.

Footers created before the key-value model render as positional rows with a
single `footerlinks` rich-text field (heading + link-list pairs). The block
still reads those, so existing content keeps working; they only need
re-authoring into the column slots to be edited with the new fields.

## How it renders

The block's decorator reads each authored field by its key, builds
the Ignite markup, and waits for the footer bundle
(`scripts/ignite/bundle/compositions/footer/xe-footer.js`) to register its
elements. Stories run that real `decorate()` against the shipped
`xe-footer-v2.css` and the same bundle, so what you see here matches production.

## Testing

- **Interaction tests** — each story's `play` function asserts the decorated
  Ignite structure (columns, links, logo, banner tagline). Run headless with
  `npm run test:storybook`.
- **Visual tests** — Chromatic snapshots each story and flags pixel diffs.
- **Accessibility** — the a11y panel runs axe checks on every story, enforcing
  WCAG 2.2 AA conformance.
