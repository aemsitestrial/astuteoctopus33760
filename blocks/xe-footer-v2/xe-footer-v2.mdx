# XE Footer V2

The **XE Footer V2** recreates the Xcel footer: a dark maroon content zone (a brand
column beside the link columns) sitting above a full-bleed banner image with a
large centered tagline.

## How it renders

The block's decorator classifies each authored row by position and structure,
then regroups them into a brand column, a link-columns grid (one column per
heading in `footerlinks`), and a banner overlay. Stories run that real
`decorate()` against the shipped `xe-footer-v2.css`, so what you see here matches
production.

## Testing

- **Interaction tests** — each story's `play` function asserts the decorated
  structure (link-column count, banner tagline). Run headless with
  `npm run test:storybook`.
- **Visual tests** — Chromatic snapshots each story and flags pixel diffs.
- **Accessibility** — the a11y panel runs axe checks on every story, enforcing
  WCAG 2.2 AA conformance.
