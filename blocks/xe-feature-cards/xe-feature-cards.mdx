# XE Feature Cards

The **XE Feature Cards** block shows a section heading and subheading above a
responsive grid of feature cards. Each card has a title, a description, and an
optional call-to-action link.

## Authoring model

The controls below map to the block's authoring model
(`blocks/xe-feature-cards/_xe-feature-cards.json`), so this page mirrors what an
author edits in the Universal Editor. The block has a container model plus a
repeatable card item.

In Storybook the repeatable cards are surfaced as a multifield: each card's
fields (Title, Description, Link text, Link) are grouped under a **Card N**
section in the Controls panel, mirroring how a multifield appears in the
Universal Editor. A fixed set of card slots is shown; a slot left blank (no
title and no description) is simply not rendered.

## How it renders

The decorator reads the first two rows as the heading and subheading, then turns
each remaining row into a card `<li>` with a title, body, and optional CTA. It
preserves authoring instrumentation via `moveInstrumentation`. Stories run that
real `decorate()` against the shipped `xe-feature-cards.css`, so what you see
here matches production.

## Testing

- **Interaction tests** — each story's `play` function asserts the decorated
  structure (card count, CTA presence, heading text). Run headless with
  `npm run test:storybook`.
- **Visual tests** — Chromatic snapshots each story and flags pixel diffs.
- **Accessibility** — the a11y panel runs axe checks on every story, enforcing
  WCAG 2.2 AA conformance.
